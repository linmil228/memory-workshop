# Мастерская памяти

Консольная викторина на C++17: 4 этапа, 10 вопросов, до 100 баллов.

## Запуск в Visual Studio Code

Откройте папку проекта через «Файл → Открыть папку», затем откройте терминал PowerShell.
С установленным компилятором g++ выполните:

```powershell
chcp 65001
g++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o quiz.exe
.\quiz.exe
```

## Правила

В меню: 1 — новая игра, 2 — правила, 0 — выход.
В вопросах вводите цифру от 1 до 3 и нажимайте Enter.
После пояснения нажмите Enter ещё раз.
За правильный ответ начисляется 10 баллов. Максимум — 100.
Новая игра сбрасывает счёт. Некорректный ввод можно повторить.

## Файлы

- main.cpp — исходный код без комментариев.
- checks.txt — результаты проверок.
